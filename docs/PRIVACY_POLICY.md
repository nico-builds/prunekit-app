# Privacy Policy — PruneKit

**Last updated:** May 22, 2026

Applies to the **PruneKit** GitHub App and **PruneKit Codebase Cleanup** GitHub Action.

## Summary

PruneKit analyzes repositories you connect via GitHub. AI processing uses the **Cursor SDK**. We do not sell source code.

## Data processed

| Data | Purpose | Retained by PruneKit |
|------|---------|----------------------|
| Repository contents | Cleanup audit / apply | No — processed in Actions or Cursor |
| `CURSOR_API_KEY` | SDK authentication | No — your GitHub Secrets |
| Org/repo metadata | PR comments, billing | Minimal (App backend JSON store) |
| Marketplace events | Plan activation | Org id, plan tier |

## Third parties

- **GitHub** — hosting, Marketplace billing
- **Cursor** — AI processing ([privacy](https://cursor.com/privacy))
